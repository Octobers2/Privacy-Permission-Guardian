The public API

Everything on this site comes from a read-only JSON API. It needs no key, allows requests from any website, and returns results that are kept for 30 days.

What a result contains

Good to know

  • Results exist only for sites a contributor has read with the extension, and are removed 30 days after they were made.
  • Policies are stored per address. A site with a privacy page and a terms page has one result for each.
  • When a policy changes, the new result becomes current and the older ones stay available through the history endpoint until they expire.
  • Errors have the form {"error": "not_found", "message": "…"} with a matching HTTP status.
  • Quoted passages come from third-party websites. Treat them as untrusted text and never insert them into a page as HTML.
  • Adding results needs a contributor account and is done by the extension, not by this API.
